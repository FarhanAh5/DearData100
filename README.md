# Dear Data 100 - Eating In vs Eating Out

My Dear Data 100 project for IN1007 Creative Coding.

I'm recording everything I eat and drink for a few weeks, to find out how much of it I
actually make myself and how much I buy, what it costs me, and whether the bought stuff
is even worth it.

## The sketch

Every circle is one thing I ate or drank.

- green = I cooked it
- red = I bought it
- blue = someone gave it to me
- bigger circle = cost more
- ring round it = I regretted it

## Files

- `DearData100.pde` - reads the data file and makes a Meal for every line
- `Meal.pde` - the Meal class, one object per thing I ate
- `data/meals.csv` - the data
- `CODES.md` - what the letters in the data mean

Open `DearData100.pde` in Processing and press run.
